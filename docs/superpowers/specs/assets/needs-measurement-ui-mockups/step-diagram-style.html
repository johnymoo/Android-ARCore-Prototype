C · 聚焦图 + 完整图入口

默认显示每步聚焦图（同 A），另给一个「查看完整示意图」按钮，点开后端那张全图当参考。兼顾干净与完整，多一个交互件。

我的推荐是 A：兜底流程的目标就是「一眼知道量哪里」，每步只画一个测量最不容易出错。也可以选 B/C，或在终端补充想法。
