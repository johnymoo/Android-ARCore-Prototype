取景时如何实时显示深度？

现状：取景只有 RGB，深度仅是一个数字「中心距离 0.25m」。下面 3 种是把 ARCore 实时深度图（近=暖色 / 远=冷色）画到取景画面上的方式。点一个你偏好的方向。

深度 ● 开
近
远

A · 全屏热力叠加（可开关）

RGB 上叠一层半透明深度热力图，右上角一键开/关，底部色标图例。最直观——一眼看清深度覆盖与盲区。

中心 0.25m

B · 画中画小窗

主画面保持清晰 RGB，角落小窗实时显示深度热力图。不挡主体，但深度细节看得不如全屏清楚。

框内 0.25m · 覆盖 ✓

C · 取景框内显示深度

中心识别框内显示深度热力，框外压暗的 RGB；附距离与覆盖提示。聚焦「要采的那块」，与识别裁剪区对齐。

技术说明：ARCore 深度图分辨率较低（约 160×120）、逐帧更新，三种方式都用一层 GL 着色器把深度上色后叠到取景上，性能可控。也可以多选/补充想法。
