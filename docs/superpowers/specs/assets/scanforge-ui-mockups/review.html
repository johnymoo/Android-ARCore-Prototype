采集后如何在 App 内查看？

现状：拍完帧只存内存/磁盘，App 内无法回看；结果页只显示后端结论。下面 3 种是"看回自己拍的每一帧 RGB / 深度"的方式。

🗑️↻
RGB深度

A · 采集中即时回看条

向导底部一条缩略图带，点开看大图，可 RGB/深度 切换、删除、重拍。聚焦"本次会话"，拍完立刻能检查。

B · 持久采集历史库

主屏入口进"我的采集"，列出历史所有采集会话与状态（已识别/待上传），点进去看每帧、可重传。像相册/历史。

C · 二合一（推荐）

采集中底部缩略图条即时回看/重拍；主屏再给一个"采集历史库"入口看过往会话与上传结果。最完整。

每帧都能切 RGB / 深度热力查看；删除会同时清掉本地留存。可点选方向，也可补充想法。
