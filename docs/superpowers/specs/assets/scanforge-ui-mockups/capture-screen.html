关键控件

深度热力可开关：右上一键开/关；开时半透明叠加在 RGB 上，近暖远冷，直接看出深度覆盖与盲区（你选的 A 方案）。

向导/自由切换：顶部分段控件。向导=分步提示+进度点（俯视→侧视→≥2 角度）；自由=随意拍，后台覆盖度状态机判断"够没够"。

实时质量条：追踪 / 距离 / 清晰度 / 焦点 四个 chip，绿色达标、橙色提示原因；不达标时快门仍可按（保留你们真机调试需要的"强拍"）。

识别框：中心裁剪/对齐框，与后端识别裁剪区一致；显示框内距离与覆盖勾。

即时回看条：左下缩略图（RGB+深度角标），点开看大图/切深度/删/重拍（第 3 节详述）。

快门 + 上传：中间大快门；凑够帧后右侧"上传 N/4"高亮可点 → 类型轻确认 → 进度。
